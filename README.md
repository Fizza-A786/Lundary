# 🧺 Laundry Service Website

A modern and responsive Laundry Service website designed to provide users with an easy and smooth experience for booking laundry services online.

🌐 Live Demo: [Laundry Service Website](https://lundary-mu.vercel.app/)

---

## ✨ Features

- 🧺 Laundry Service Showcase
- 📱 Fully Responsive Design
- ⚡ Fast & Optimized Performance
- 🎨 Clean & Modern UI
- 🧼 Service Details Section
- 💳 Pricing & Packages
- 📞 Contact & Booking Section
- 💻 Reusable Components
- 🚀 Deployed on Vercel

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Vite
- CSS3
- Vercel
